### 📊 [**Data Warehouse and Analytics Project**](https://github.com/matheusaragaofs/sql-data-warehouse-project)

This project showcases a comprehensive data warehousing and analytics solution, from building the warehouse to generating actionable insights. It emphasizes industry best practices in data engineering and analytics through a modern cloud-based architecture.

**Key aspects:**
* **Data Architecture**: Designed a Modern Data Warehouse following the **Medallion Architecture (Bronze, Silver, Gold layers)**.
    * **Bronze**: Stores raw data directly from CSV files into SQL Server.
    * **Silver**: Focuses on data cleansing, standardization, and normalization.
    * **Gold**: Houses business-ready data, modeled into a star schema for reporting and analytics.
* **ETL Pipelines**: Developed robust processes for **Extracting, Transforming, and Loading** data into the warehouse.
* **Data Modeling**: Created **fact and dimension tables** optimized for analytical queries.
* **Analytics & Reporting**: Generated **SQL-based reports** and dashboards to provide actionable business insights.
* **Technologies**: Primarily **T-SQL** and **SQL Server**.
